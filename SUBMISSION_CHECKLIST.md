# Submission Checklist

Use this before final submission to ECRIO.

## Already included in GitHub

- Source code for mini projects and exercises
- README files explaining implementation choices
- DOCX report
- PDF report
- Video explanation guide

## Optional files to add if your teacher asks for proof

- The original assignment Excel sheet, if you are allowed to upload it publicly.
- Any official Titanic CSV or dataset file if it was provided separately by the course.
- Screenshots of output only if the portal specifically asks for them.
- Video file or video link. A link is usually better because video files can be large for GitHub.

## Recommended video approach

Record a 4-5 minute video using this order:

1. Open the report or a small PPT and explain the project journey.
2. Open GitHub and show the README.
3. Show two code highlights: one OOP/test example and one data/Flask/MQTT example.
4. End with what you learned.

This is better than only reading code because selection reviewers need to quickly understand your design decisions.
